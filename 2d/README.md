# SEOUL 209X — 마지막 불빛 / 2D

Canvas 2D로 새로 만든 아이소메트릭 픽셀 게임입니다. WebGL, Three.js, 외부 라이브러리, 외부 에셋 요청 없이 실행합니다. 모든 풍경과 캐릭터는 game.js의 Canvas 드로잉으로 생성합니다.

## 실행

GitHub Pages: `https://kimhoyul.github.io/seoul-209x/2d/`

로컬에서는 이 폴더의 `index.html`을 브라우저로 열거나 `python -m http.server 8000`으로 실행하세요. `index.html`, `style.css`, `game.js`를 같은 폴더에 둡니다.

## 조작

휴대폰: 왼쪽 조이스틱 이동, 달리기 전환, 조작 버튼. PC: WASD / 방향키 이동, Shift 달리기, E 상호작용. 바닥을 누르면 자동 이동합니다. 현재 목표 또는 이름표를 누르면 장애물을 피해서 이동 후 조작합니다. 전체 보기, 확대/축소, 황혼/야간 전환, 선택적 효과음이 있습니다.

## 플레이

퓨즈 획득 → 발전기 시동 → 108.7 MHz 주파수 조정 → 컴퓨터 신호 송신 → 생존자 응답. 텃밭, 고양이, 침대의 일상 기록 3개를 별도로 수집할 수 있습니다. 진행은 localStorage에 저장하며 ? 도움말에서 새 게임을 시작할 수 있습니다. 브라우저 저장이 금지된 환경에서도 게임은 실행되지만 기록은 유지되지 않습니다.

## 검증 범위

헤드리스 Chromium에서 키보드 이동, A* 자동 이동으로 전체 메인 임무 완료, 잘못된 주파수 차단, 부가 기록 3개, 야간 전환과 경계 충돌을 검증했습니다. 터치 이벤트로 조이스틱 이동/해제, 달리기 전환을 검증했습니다. 390×844, 844×390, 360×740 뷰포트의 조작 UI 배치도 확인했습니다. 실제 iPhone Safari 하드웨어 성능은 별도 검증이 필요합니다.

이전 배포 3D 버전은 `../archive/threejs-rooftop.html`에 원본 그대로 보관되어 있습니다.
